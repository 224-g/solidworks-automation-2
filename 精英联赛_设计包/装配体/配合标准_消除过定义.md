# 齿轮传动曲柄滑块机构 — 装配配合标准（消除过定义）

目标：**1 个自由度**（单原动件 = 主动轴），无过定义/冗余配合，运动链完整可动。

---

## 一、为什么原来的装配体会过定义

原脚本（sw_asm_build3.cs）为了"保险"给很多零件加了多余配合，典型问题：

| # | 过定义来源 | 为什么错 |
|---|---|---|
| 1 | 连杆加了 **3 个配合**（两端同心 + 端面重合） | 连杆两端各一个同心就已定位，端面重合是冗余 → 连杆过定义 |
| 2 | 滑块同时配合到**底板**（SL_TOP-PLATE_TOP）+ 导轨 + 连杆 | 滑块只该和导轨配合留 X 滑动，配到底板后与连杆的约束冲突 |
| 3 | 电机既和**主动轴同心**，又用**脚面配到底板** | 双重定位，轴向/径向冗余 |
| 4 | 齿轮/曲柄**没锁定到轴**（能相对轴打滑）+ 齿轮配合叠加 | 运动链不闭合；且多处轴向面配合互相重复 |
| 5 | 齿轮配合之外再叠加距离/相切 | 中心距由支架决定，再加距离就是冗余 |

**核心原则**：机架类零件"3 个配合完全固定"；运动链零件"只留它该有的自由度"，绝不重复约束。

## 三、关于「锁定」配合的说明（重要）

- 齿轮、曲柄要**随轴一起转**，所以需要锁定。SolidWorks 里「锁定」在 **配合 → 标准 → 锁定（Lock）**。
- 推荐顺序：先「同心 + 重合」把齿轮/曲柄定位到轴上，再「锁定」。
- **如果 SolidWorks 对「同心+重合+锁定」报过定义**（部分版本锁定会重复约束），二选一：
  1. 删掉「同心+重合」，手动把齿轮/曲柄拖到正确位置后，**只用「锁定」一个配合**；
  2. 或省略锁定，接受齿轮相对轴可自由转动（静态展示外观不变，只是拖动时齿轮不跟轴走）。

## 四、结果核对

- 配合总数 ≈ **44 个**（机架 36 + 运动链 8 个定位/锁定 + 齿轮配合 1）。
- 自由度 = **1**：转动主动轴 → 主动齿轮 → 从动齿轮 → 从动轴 → 曲柄 → 连杆 → 滑块，整套机构联动。
- 若仍报过定义，按优先级排查：① 连杆是否多加了端面配合 → ② 滑块是否配到了底板 → ③ 齿轮是否同时有「齿轮配合 + 距离/相切」→ ④ 电机是否既同心轴又配底板。
