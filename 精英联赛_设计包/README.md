# 齿轮传动曲柄滑块机构 —— 精英联赛参赛作品

**作者**：智能制造工程专业（大二）
**软件**：SolidWorks 2024 SP5
**规模**：17 种零件 · 24 个零部件实例 · 59 个装配配合 · 1 个齿轮机械配合

## 作品简介

一套单自由度**齿轮传动曲柄滑块往复机构**演示装置：
电机 → 齿轮减速（i=2）→ 曲柄旋转 → 连杆 → 滑块往复 → 推头执行动作。

- 齿轮：标准直齿圆柱齿轮 m=2，z₁=20 / z₂=40，渐开线齿形，中心距 60.3（含 0.3 齿侧间隙）
- 曲柄滑块：r=35，L=85，行程 70mm，对心式（无急回）
- 结构亮点：D 形扁位防转联接、推头极限位置 0.5mm 演示工件定位、全参数化设计

## 快速开始

1. 打开 `CAD\齿轮传动曲柄滑块机构.SLDASM`
2. 鼠标拖动主动齿轮 → 全机构联动
3. 左下角「运动算例」→ 计算 → 播放动画
4. 按 `02_装配步骤.md` 第 4 节做干涉检查与验证
