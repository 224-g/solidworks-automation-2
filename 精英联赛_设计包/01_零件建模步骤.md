# 零件建模步骤（17 个零件 · SolidWorks GUI 教程）

> 说明：本套零件已用 SolidWorks API 自动化批量建模完成（`sw_build_parts.vbs`）。
> 本文给出**手工 GUI 操作步骤**，与自动化脚本一一对应，供答辩演示与复现使用。
> 单位 mm；坐标约定：前视基准面（X-Y，沿 Z 拉伸）、上视基准面（X-Z，沿 Y 拉伸）。
> 模板：`gb_part.prtdot`（GB 国标模板）。

---

## 通用操作提醒

- 新建零件 → 选择 GB 模板
- 草图必须**完全闭合**才能拉伸/旋转成实体
- 拉伸切除：特征 → 拉伸切除 → 「完全贯穿」
- 齿轮的渐开线轮廓用 **9 点样条**拟合（见 6 号零件）

## 6. 主动齿轮（z=20）/ 7. 从动齿轮（z=40）—— 重点零件

### 6.1 齿坯（旋转凸台）

1. 上视基准面草图：
   - 中心线：从 (0,0) 到 (0,24)（旋转轴）
   - 轮廓折线：(0,0)→(8,0)→(8,6)→(22,6)→(22,18)→(8,18)→(8,24)→(0,24)→闭合
   - （轮毂内孔 Ø16、辐板厚 12、齿圈宽 12）
2. 旋转凸台：360°

### 6.2 渐开线齿形（两种做法任选）

**做法 A（GUI 推荐，方程式驱动曲线）**

用「工具 → 草图工具 → 方程式驱动的曲线」，参数方程（t 为参数，rad）：

```
x = rb * (cos(t) + t*sin(t))
y = rb * (sin(t) - t*cos(t))
t 从 0 到 t_a
```

其中：基圆半径 rb = m·z·cos(20°)/2，t_a = √((ra/rb)²−1)，ra = 齿顶圆半径。

- z=20：rb=18.794，t_a=0.6085
- z=40：rb=37.588，t_a=0.4983

镜像得到另一侧齿廓，两齿廓间画齿顶圆弧（半径 ra）与齿根圆弧（半径 rf），齿根过渡用径向直线闭合 → 得到**一个齿槽轮廓**。

**做法 B（本套件实际采用）**

每个齿槽 = 6 段曲线（齿根弧 → 右渐开线样条 → 齿顶弧 → 左渐开线样条 → 2 条径向过渡线），公式如下（φ_k=2πk/z 为第 k 个齿槽中心角，inv=tanα−α）：

- 右齿廓（基圆→齿顶）：r = rb·√(1+u²)，θ = φ_k + π/(2z) + inv20° − (u − atan u)，u∈[0,t_a]
- 左齿廓（齿顶→基圆）：θ = φ_k + 3π/(2z) − inv20° + (u − atan u)

3. 圆周阵列：齿槽轮廓绕原点阵列 z 个（20 / 40）
4. 拉伸切除：完全贯穿（+Z 方向）→ 齿轮成型

### 6.3 D 形孔（与轴配合的防转孔）

前视草图：弦线+圆弧围成「下半月形」区域（Ø10.2 圆切掉上部，弦距中心 2mm）。
**相位角**：主动齿轮扁位中心转 94.5°，从动齿轮转 83.25°（保证啮合相位，装配即啮合）。
拉伸切除：完全贯穿。

## 建模技巧备忘

- **D 形扁位/孔**：先画弦线，再用三点圆弧从弦一端经要保留侧回到另一端，与弦围成闭合区域
- **方程式驱动曲线**：SolidWorks 自带，是画渐开线的最规范方法（答辩可演示）
- **圆周阵列**：齿槽轮廓阵列比逐个画快得多
- 保存路径：`精英联赛_设计包\CAD\`，文件名用中文零件名（如「主动齿轮.SLDPRT」）
