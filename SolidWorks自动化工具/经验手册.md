# SolidWorks 2024 C# API 自动化 —— 经验手册（问题 → 根因 → 方案）

> 本手册汇总了「齿轮传动曲柄滑块往复机构」从零件建模到装配配合全流程中遇到的所有问题、根因与最终解决方案，以及经过多轮实测验证的 API 结论。用于未来任何 SolidWorks 自动化任务，避免重踩同样的坑。

---

## 0. 一句话结论（最终可复用架构）

- **固定件用 `FixComponent()` 固定（0 个配合），绝不靠 3 个平面配合定位** —— 这是消除过定义的唯一可靠办法。
- **运动链只加最小配合**（每个自由度一个配合），用 `err` 返回值（`err==5` = 过定义）自检。
- **同心配合选轴/孔**：轴 OD ↔ 孔 HOLE 用 `align=0 + flip=true`（或 `align=1`），否则会 180° 翻转（镜像到错误一侧）。
- **点-面配合**（`MateVertex`）用于"只约束一个平动方向"的场景，避免平面距离配合的旋转冗余。

## 1. 问题清单（按阶段）

### 1.1 建模阶段

| 问题 | 根因 | 方案 |
|---|---|---|
| 切除(cut/extrude-cut) API 失灵 | 本机 SolidWorks 切除特征 API 不稳定 | 全部零件改用**拉伸建模**（程序化轮廓 + `FeatureExtrusion`），避开切除 |
| 渐开线齿轮轮廓 | 需精确齿形 | 程序化生成渐开线齿廓点列 → 封闭草图 → 拉伸 |

### 1.2 装配配合阶段（核心难点：过定义）

| # | 问题 | 根因 | 方案 |
|---|---|---|---|
| 1 | **过定义**（`err=5 OverDefinedAssembly`）反复出现 | 每个固定件用 3 个"平面距离"配合（BOT+BACK+LEFT，type=5）定位 → 3 平面 × 3 约束 = 9 约束，但只有 6 自由度 → 旋转方向双重约束 → 第 3 个平面配合必报过定义 | **固定件改用 `FixComponent()`**（0 个配合） |
| 2 | 脚本重跑会累积配合 | `DeleteMateGroup` 不可靠（返回 `False`，配合没删掉） | **用"全新装配"而非"改现有装配"**：`NewDocument` + `AddComponent5` 重建，绕开删除 |
| 3 | 点-面配合后 X 取负（零件跑到 -0.090 而不是 +0.090） | 点-面 `align=0` 把顶点放到平面错误一侧 | 点-面距离配合优先用 `align=0 + d=0`（共面）；若需偏置，核对顶点实际落点后用对侧 align |
| 4 | 轴/齿轮/曲柄整体下陷到 y=-0.053（应为 +0.077） | 轴 OD（外圆柱）与支架 HOLE（内孔）的**轴向参数化相反**，同心配合 `align=0` 造成 180° 翻转（镜像） | 同心配合用 **`align=0 + flip=true`**（或 `align=1` 反对齐）。注意：单纯改 align 0/1/2 都不行，必须在 FixComponent 固定住参照件的前提下 `flip=true` 才稳定 |
| 5 | 滑块 TOP 配合过定义（与连杆链冗余） | 滑块 Y 同时被「滑块 TOP 距离」和「连杆 E2→滑块孔 同心」约束，冗余 | 滑块只保留 1 个 Y 约束（TOP 距离）+ 1 个 Z 约束（点-面），去掉多余的平面距离配合 |
| 6 | 点-面配合 d=0.024 把滑块推到 z=0.084（超出连杆销孔 z∈[0.052,0.060]） | 偏置方向错误 | 用 `d=0`（共面）保持设计位置 z=0.060 |
| 7 | 方向性错误（零件放到参照面相反一侧） | `align=0` 的约定是 `face2 = face1 + d·(face1法向)`；当两个面的法向**同向**（都 +y 或都 -z）且 d>0 时，face1 被放到错误一侧 | 同向面对 + d>0 → **交换面顺序**（谁做 face1/face2 反过来）或 `align=1` |

## 2. 方向约定（实测确认）

`AddMate5(type, align, flip, d, ...)` 中，对**距离配合**（type=5）：

```
align=0（对齐）：face2 = face1 + d · (face1 的法向)
align=1（反对齐）：face2 = face1 + d · (-face1 的法向)
```

判断规则：
- 两参照面**法向相反**（一个 +y 一个 -y）→ `align=0` 直接正确。
- 两参照面**法向相同**（都 +y 或都 -z）且 d>0 → `align=0` 会把 face1 放到错误一侧，应**交换面顺序**或改用 `align=1`。

本项目实测 6 处方向修正（交换面顺序、保持 align=0）：
1. 主动轴 BACK ↔ 支架 BACK d=0.020
2. 曲柄 FRONT ↔ 从动齿轮 HUBFRONT d=0.012
3. 曲柄销 FRONT ↔ 曲柄 FRONT d=0.012
4. 滑块 TOP ↔ 底板 TOP d=0.093
5. 砧台 TOP ↔ 底板 TOP d=0.018
6. 工件 TOP ↔ 砧台 TOP d=0.034

## 3. API 参考（反射实测，逐字保留）

### 3.1 `AddMate5` 签名（15 个参数，位置 0–14）

```
0  int    MateTypeFromEnum     （配合类型）
1  int    AlignFromEnum        （对齐方式 0/1/2）
2  bool   Flip                 （翻转）
3  double Distance             （距离）
4  double DistanceAbsUpperLimit
5  double DistanceAbsLowerLimit
6  double GearRatioNumerator   （齿轮比分子）
7  double GearRatioDenominator （齿轮比分母）
8  double Angle
9  double AngleAbsUpperLimit
10 double AngleAbsLowerLimit
11 bool   ForPositioningOnly
12 bool   LockRotation         （同心配合上锁旋转 = 免去单独 Lock 配合）
13 int    WidthMateOption
14 out int ErrorStatus         （err 返回值）
```

原始调用 `AddMate5(type, align, false, d, 0,0, rn, rd, 0,0,0, false, lockRot, 0, out err)`
→ `rn` 映射到 GearRatioNumerator(#6)，`rd` 映射到 GearRatioDenominator(#7)。

### 3.2 `swAddMateError_e`（err 返回值）

```
ErrorUknown = 0         （未知/失败，配合返回 NULL）
NoError = 1             （成功）
IncorrectMateType = 2
IncorrectAlignment = 3
IncorrectSelections = 4
OverDefinedAssembly = 5 （过定义！）
IncorrectGearRatios = 6
```

### 3.3 `swMateType_e`（配合类型，关键值）

```
COINCIDENT = 0   CONCENTRIC = 1   DISTANCE = 5   GEAR = 10   LOCK = 16
```

### 3.4 关键对象方法（反射确认）

- **`Edge`（IEdge）**：有 `GetStartVertex()` / `GetEndVertex()`（返回 `Vertex`），**没有** `GetTwoVertices()`（编译报 CS1061）。
- **`Vertex`（IVertex）**：**没有** `Select`/`Select4` 方法，**不继承** `IEntity`（只有 `Face2`/`Edge` 继承）。选顶点必须用 `ModelDocExtension.SelectByID2("", "VERTEX", wx, wy, wz, false, 0, null, 0)`，且坐标必须是**世界坐标**。
- **`Vertex.GetPoint()`**：返回 `double[]`（**不是** `MathPoint`）。转世界坐标：`((MathPoint)mu.CreatePoint(lp)).MultiplyTransform(c.Transform2)` 再读 `ArrayData`。
- **`ModelDoc2.Save()`**：返回 `void`（**不是** bool，写成 `bool saved = ad.Save()` 会 CS0029）。
- **`AssemblyDoc.SaveAs3(name, options, silent)`**：3 参数（不是 2 参数）。
- **`IMathUtility.CreateTransform(16个double)`** 约定：`[0-8]`=3×3 旋转，`[9-11]`=平移，`[12]`=缩放，`[13-15]`=0。
- **`IAssemblyDoc.FixComponent()` / `IComponent2.IsFixed`**：固定/判断固定。
- **齿轮配合比**：`GearRatioNumerator:GearRatioDenominator = z1:z2`。本例 z1=20/z2=40 → rn=1, rd=2（ratio 1:2）。外啮合自动反转。

## 4. 编译 / 运行环境坑

| 坑 | 方案 |
|---|---|
| `csc` 不在 PATH | 用完整路径 `& "C:\Windows\Microsoft.NET\Framework64\v4.0.30319\csc.exe"` |
| exe 运行时 CLR 异常 exit `0xE0434352` | 两个 Interop DLL（`SolidWorks.Interop.sldworks.dll` + `SolidWorks.Interop.swconst.dll`）**必须放在 exe 同目录** |
| 编译命令 | `csc /nologo /r:SolidWorks.Interop.sldworks.dll /r:SolidWorks.Interop.swconst.dll /out:xxx.exe xxx.cs` |
| PowerShell 反射加载 DLL | `[System.Reflection.Assembly]::Load([System.IO.File]::ReadAllBytes(path))`（`LoadFrom` 会报 NotSupportedException 0x80131515） |
| .ps1 用 `-File` 运行含中文 | 需 UTF-8 BOM（`[System.Text.UTF8Encoding($true)]`），否则中文解析报 ParserError。用 `pwsh -Command` 内联则无此问题 |
| SolidWorks COM 启动 | `Activator.CreateInstance(Type.GetTypeFromProgID("SldWorks.Application"))` |
| 打开零件 | `OpenDoc6(path, 1, swOpenDocOptions_Silent, "", ref e, ref w)` |
| 新建装配 | `NewDocument(template.gb_assembly.asmdot, 0, 0, 0)` |
| 释放被锁的文件 | `app.CloseAllDocuments(false)`（写在独立小脚本 sw_close.cs 里） |
| 装配文件被 SolidWorks 锁住无法覆盖 | 先关文档、再覆盖 .bak 备份 |

## 5. 最终架构（0 过定义，实测通过）

### 5.1 原则
1. **固定件**（底板、支架、塔、导轨、电机、砧台、工件、螺栓、螺母）→ `FixComponent()` 固定在设计位姿，**0 个配合**。
2. **运动链**（轴、齿轮、曲柄、销、连杆、滑块）→ 每个自由度 1 个配合，共 **17 个配合**。
3. 每次加配合后检查 `err`：`err==5` 立即记录并分析。

### 5.2 17 个运动链配合清单

| 配合 | 类型 | 关键参数 |
|---|---|---|
| 主动轴 ↔ 支架A（同心） | CONCENTRIC(1) | `align=0, flip=true`（修 Y 镜像） |
| 支架A ↔ 主动轴（轴向 Z） | DISTANCE(5) | `align=0, d=0.020`（面顺序交换） |
| 从动轴 ↔ 支架B（同心） | 1 | `align=0, flip=true` |
| 从动轴 ↔ 支架B（轴向 Z） | 5 | `align=0, d=0` |
| 主动齿轮 ↔ 主动轴（同心） | 1 | `align=2, LockRotation=true`（锁旋转） |
| 主动齿轮 ↔ 支架A（轴向） | 5 | `align=0, d=0.012` |
| 从动齿轮 ↔ 从动轴（同心） | 1 | `align=2, LockRotation=true` |
| 从动齿轮 ↔ 支架B（轴向） | 5 | `align=0, d=0.012` |
| 主动齿轮 ↔ 从动齿轮（齿轮配合） | GEAR(10) | `rn=1, rd=2`（z1:z2=20:40） |
| 曲柄 ↔ 从动轴（同心） | 1 | `align=2, LockRotation=true` |
| 从动齿轮 ↔ 曲柄（轴向） | 5 | `align=0, d=0.012` |
| 曲柄销 ↔ 曲柄（同心） | 1 | `align=2` |
| 曲柄 ↔ 曲柄销（轴向） | 5 | `align=0, d=0.012` |
| 连杆 E1 ↔ 曲柄销（同心） | 1 | `align=2` |
| 连杆 E2 ↔ 滑块孔（同心） | 1 | `align=2` |
| 底板 ↔ 滑块（TOP 距离） | 5 | `align=0, d=0.093`（面顺序交换） |
| 滑块 BACK ↔ 导轨壁（点-面 Z） | MateVertex | `align=0, d=0`（共面） |

### 5.3 结果
`TOTAL mates=17 overdefined=0`，全部 24 个零件在设计位姿，机构 1 自由度（F=1）。
