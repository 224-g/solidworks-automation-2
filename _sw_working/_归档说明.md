# SolidWorks 自动化工作文件归档说明

> 归档时间：2026-11-13
> 来源：「齿轮传动曲柄滑块往复机构」SolidWorks 2024 API 自动化建模过程的中间工作文件（脚本 + 日志 + 临时零件/截图）。最终成果已归档到 `..\精英联赛_设计包\`。本目录仅用于追溯建模过程，不参与后续交付。

## 分类总览

| 子目录 | 文件数 | 说明 |
|---|---|---|
| 01_interop_dll | 2 | SolidWorks COM 互操作 DLL（sldworks.dll + swconst.dll），C# 程序引用 SolidWorks API 类型库所需。 |
| 02_diag_probes | 255 | 诊断探针（sw_diag*.vbs + 日志 + 临时测试零件/截图），逐项排查 SolidWorks API 行为；发现本机切除(Cut)API 失灵后改用拉伸(Extrude)建模；sw_diag22 生成第一个 z=20 渐开线齿轮。 |
| 03_part_builders | 7 | 零件生成脚本（sw_build_parts / v7 / v8.vbs + 日志），批量绘制 17 个零件输出到 sw_parts8\。 |
| 04_assembly_builders | 22 | 装配生成脚本（sw_asm_build*.cs/.exe + sw_asm_probe*.vbs + 中间 .SLDASM），最终版 sw_asm_build3.cs 按精确面规格完成装配。 |
| 05_cs_probes | 30 | C# 探针（sw_cs_probe/comp_walk/face_dump/face_probe/layout_probe/mate_probe/math_probe/pick_probe/ray_retest/reflect/probe_select），枚举装配体组件/面/配合/数学关系。 |
| 06_drawings_verify_fix | 11 | 工程图生成与校验修复（sw_drawings.ps1 生成 17 张 SVG 工程图；sw_verify*/sw_fix*/sw_patch* 校验与修复）。 |
| 07_utility | 17 | 工具脚本（sw_kill/sw_exit 关闭 SW、sw_keepawake 防休眠、sw_runner/sw_poll/sw_http 运行与轮询、sw_typelib/sw_tlbdump 类型库、sw_macro_probe.swb/sw_run_macro.vbs 宏）。 |
| 08_early_modeling | 23 | 早期建模试验（sw_model*/shaft/gasket/six/test*/save + sw_probe.vbs/log），最初验证 SolidWorks API 的脚本。 |
| 99_misc | 0 | 未归类（应为空）。 |
